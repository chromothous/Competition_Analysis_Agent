# Competition Analysis Agent

An AI powered workflow built during the **Extern Wayfair AI Automation Externship** that automates competitor research by collecting, analyzing, and summarizing competitive intelligence. The agent helps businesses understand competitor positioning, pricing strategies, product offerings, and market opportunities through AI generated reports.

---

## 🛠️ Technologies

* n8n
* Open Router and Mistrel AI
* AI Prompt Engineering
* REST APIs
* Web Data Collection
* HTML Report Generation
* Data Transformation
* Competitive Intelligence Automation

---

## ✨ Features

* Collects competitor information from multiple online sources
* Compares competitor products and market positioning
* Identifies pricing and product strategy trends
* Summarizes findings using AI
* Generates structured competitor analysis reports
* Produces actionable business insights
* Modular workflow designed for future expansion

---

## 🔄 Process

1. User selects a product category.
2. The workflow gathers competitor information from publicly available sources.
3. Product, pricing, and positioning data is cleaned and organized.
4. Open Router and Mistrel analyzes the collected competitor information.
5. The AI generates a comprehensive competitive analysis report.
6. The report is formatted into an organized HTML document for business review and downstream workflows.

## ▶️ Running the Project

### Prerequisites

* n8n installed or hosted
* Google Gemini API credentials
* Internet connection for data collection
* Required API credentials configured within n8n

### Steps

1. Import the workflow into n8n.
2. Configure all required credentials.
3. Enter the desired product category.
4. Execute the workflow.
5. Review the generated HTML competitor analysis report.
